# ChiefKit Studio 3.0 Wiki

ChiefKit Studio 3.0 Master Suite is a native macOS SwiftUI IDE, visual design & animation studio, bidirectional AST compiler, enterprise blueprint composer, cryptographic & `EphemerisCore` workbench, and 100% on-device AI assistant for the HNMLabs ChiefKit ecosystem:

- **SwiftBlocks 3.0** — Drag-and-drop canvas, 64 components, OKLCH/APCA color science, RK4 spring physics, W3C SVG engine, and 8-target token compiler
- **SwiftState 3.0** — Unidirectional reducers, actor-safe `StudioStore` middleware, causal history DAG, and floating Time-Travel Debugger (`⌘T`)
- **NotebookFlowKit 3.0** — Visual step builder, conditional expression runtime, ISO-13616 Mod-97 IBAN/field validators, and Jupyter `.ipynb` export
- **CoreLocalAIKit + ChiefKitAST** — 100% offline EN/TR assistant, recursive-descent `@ViewBuilder` parser, 38 static audit rules, 6 AST refactoring passes, and `@Test` synthesis
- **ChiefKitSecurity + EphemerisCore** — Pure-Swift FIPS 180-4 SHA-2, HKDF, RFC 8439 ChaCha20-Poly1305 / XChaCha20 vault, Shamir `GF(2^8)` secret sharing, 9-body planetary auth, 30 OWASP SAST rules, and `PrivacyInfo.xcprivacy` builder
- **ChiefKitBlueprints** — 28 full-stack enterprise architectures across 9 industry verticals with 14-file SwiftPM project export
